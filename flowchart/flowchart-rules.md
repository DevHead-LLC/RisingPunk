# Flowchart Development Rules

## Purpose
This file establishes guidelines for creating a simple yet effective flowchart application using HTML, CSS, and JavaScript. The goal is to ensure that both the AI and user are on the same page during development.

## Visual Requirements
- Create a flowchart similar to the provided images
- Maintain similar color scheme (green for automated processes, yellow/orange for user actions, blue for informational components)
- Support for different node shapes (rectangles, rounded rectangles, diamonds)
- Connected nodes with directional arrows
- Text labels for nodes and connections

## Technical Requirements
- Simple HTML/CSS/JS implementation
- No need for dragging/moving elements
- Support for creating a connected tree of activities
- Arrows pointing between elements in multiple directions
- Informational boxes with clear text

## Development Approach
1. Start with basic HTML structure and CSS styling
2. Implement a simple grid-based layout
3. Create node and connector components
4. Establish a clear visual hierarchy
5. Add basic interactivity if needed

## Success Criteria
- Flowchart visually represents process workflows
- Clear visualization of decision points and actions
- Consistent styling throughout
- Easy to understand without excessive complexity
